# 足球+力量周计划

- 状态：进行中
- 创建：2026-10-17
- 约束：每周四晚、周日各一场足球比赛（比赛日不练力量）

## 周计划表

| 日 | 内容 |
|----|------|
| 周一 | 完全休息（周日赛后恢复；可散步/拉伸/泡沫轴） |
| 周二 | 腿日（本周最重要）：深蹲或硬拉 → RDL → 腿弯举 → 北欧挺 2 组 → 哥本哈根 2 组 → 慢跑 2–3km |
| 周三 | 胸 + 三头 → 慢跑 3km（强度压低，为周四留力） |
| 周四 | ⚽ 比赛（充分热身；赛后补水+快碳+蛋白） |
| 周五 | 背 + 二头（引体/下拉 → 划船 → 面拉 → 弯举）→ 慢跑 3km |
| 周六 | 肩 + HYROX mini 循环（见 hyrox-prep 项目） |
| 周日 | ⚽ 比赛 |

## 核心原则

1. 腿日固定周二：与两场比赛的恢复间隔最优
2. 腿日与任何比赛间隔 ≥48h
3. 北欧挺 + 哥本哈根是防伤底线（腘绳肌/腹股沟），不可省略
4. 周三跑步宁慢勿快；比赛前 1.5h 只补快碳，不再摄入大量蛋白/脂肪

## 有氧结构

- 基础：周二/三/五跑步约 9km（Zone 2 为主）
- 间歇（可选）：不比赛周把周三换成 400m×6 间歇 @ ~4'00/km
- HYROX mini 循环本身即高强度间歇

## 替代课表：下肢功能性 + Zone 2 日（腿日替代）

> 2026-10-18 首次执行并沉淀；适用：原定腿日无法安排大重量主项时

- 功能性力量（乐刻）：保加利亚分腿蹲 → 单腿 RDL → 壶铃摇摆 → 哑铃俯卧撑
- 跑步：10km，目标 Zone 2，配速 6'15–6'30/km（10-18 实际 6'00/km、Z4+ 占 36% 偏高，须压速）
