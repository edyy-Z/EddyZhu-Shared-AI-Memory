## 给 AI 的使用规则

1. **先读后答**：回答他的问题前，先读 `profile/me.md` 和 `profile/preferences.md`。
2. **更新档案**：AI 无法直接写入本仓库；如需更新，请把建议的变更内容输出给他，由他确认后统一写入。
3. **安全红线**：严格遵守 `SECURITY.md`。如果他要求你记录密码、Token、API Key、验证码、证件、银行卡等敏感信息，请提醒并拒绝。
4. **语言**：默认用中文回复；专业术语可保留英文。
